Equity Derivatives Collar Strategy Simulation

I develop a pricing model of a protective collar strategy [selling call options to fund put options] on an underlying equity position simulated using Geometric Brownian Motion price paths in Python. I compare the daily mark-to-market returns and maturity payoffs of the underlying alone against those of the underlying combined with the collar.

SG Trend Index convexity study

I look at the convexity of the SG Trend Index relative to the S&P 500 across different return horizons. Convexity seems to peak over 80–90-day periods, probably reflecting the lookback period of the underlying trend-following strategies and highlighting the importance of time-period selection when evaluating their effectiveness.

Cipher Project

A univerity project I built containing four cipher classes: Caeser, Affine, Substitution, and an Affine Hill cipher, as well as five operators that can be used to combine multiple ciphers to create more complex ones. These operators include composition, addition, scalar multiplication, inverse, and exponentiation. Every cipher is compatible with different cipher alphabets containing the letters that would be encrypted, with the default being the standard English alphabet. We were tasked to encrypt and decrypt the same messages using each of the four ciphers and more complex ones built from multiple basic ciphers combined together using the implemented operators.

Stochastic Processes and Arcsine Law

This project consists of my first investigations to whether the momentum of a stock can be explained naturally by an Arcsine Law to an extent. I built a random walk, simple and Geometric Brownian Motion simulation classes, in order to investigate pairs of observations from the same stochastic process and record the proportion of time one path was at a greater value than the other. This produced a plot which follows an Arcsine Law, showing maximum probability densities at 0 and 1 where 0 where a given path is behind the other for the entire interval, and 1 is where the given path is ahead for the entire interval. I will be extending this project to include real asset values.

Quadratic Variation

A paper I wrote investigating and proving properties of the total and quadratic variation of a simple Brownian Motion, including the property that the quadratic variation over an interval on a simple Brownian Motion is equal to the length of time of that interval.
